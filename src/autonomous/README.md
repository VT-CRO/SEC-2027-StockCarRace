# Autonomous
A skeleton for the autonomous behavior of the robot

## Breakdown
This package will contain the **autonomous behavior** of the robot, including the vision and localization nodes.

Libraries that can be utilized:
- Nav2: The navigation software (https://docs.nav2.org/rolling/)
- BTCPP (Behavior Tree): The behavior tree library
- RVIZ2: Robot visualization for localization
- apriltag_ros: Apriltag library

These libraries do not have to be used if you don't want to. If you do find a different library, run it through me first.
